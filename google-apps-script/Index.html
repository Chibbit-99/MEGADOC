Export to Google Docs

Export a MegaDoc tab with supported formatting, or paste plain text or structured JSON. You can also open this app from MegaDoc’s Google Docs export dialog.

Only use this page when you intentionally opened your trusted deployment. An embedded page can be disguised by other websites; if anything looks unexpected, close it and open the deployment directly.

Content is sent to Google Apps Script and the Google Docs API when you export. Use only a deployment you trust. Existing document overwrites are permanent changes; make a backup first.

Replace an existing Google Doc

Only simple, single-tab documents without comments, suggestions, lists or special objects are eligible. The existing text and formatting will be replaced; document metadata may remain.

Listing recent documents requires permission to view files in Google Drive. Shows up to 20 recent matching documents from your accessible Drive and shared drives. Some results may be missing; search by the beginning of its name or paste a document URL. Edit access is checked when you inspect.

Overwrite confirmation

Type the exact title of the existing Google Doc shown above (not the MegaDoc tab title), then confirm. This replaces the existing text.
